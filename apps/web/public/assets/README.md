# Starhold UI assets

Original vector art drawn for this project (SVG). **Not** scraped or copied from OGame, Gameforge, or other proprietary games.

## License / source

| Field | Value |
|-------|--------|
| Author | Starhold prototype (this repository) |
| License | Same as the Starhold repo (project learning use) |
| Style | Flat icon plates matching the web UI palette |
| Formats | SVG (lightweight; crisp at any DPI) |

## Layout

| Folder | Contents |
|--------|----------|
| `buildings/` | Ore Extractor, Crystal Lattice, Deut Still, Solar Array, vaults, tank, Shipyard, Research Lab |
| `ships/` | Scout Skiff, Ore Hauler, Interceptor, Whisper Probe, Salvage Trawler, Colonizer |
| `planets/` | Rocky world + colony plate for roster / planet header |
| `defenses/` | Beam Emplacement + Aegis Cupola (buildable) |
| `resources/` | Metal, crystal, deuterium, energy chips |
| `ui/` | Empty hangar placeholder |

Filenames are kebab-case and mapped in `apps/web/src/ui/assets.ts`.
